# 睡眠小程序

## 项目介绍
睡眠小程序是一款专注于睡眠健康与大脑认知训练的微信小程序。通过记录和分析用户的睡眠数据，结合认知、情绪和心理评估，为用户提供个性化的睡眠改善建议和脑力训练方案。

## 功能特点
- 用户登录与授权
- 睡眠数据记录与统计
- 大脑认知训练
- AI睡眠顾问
- 个人健康数据分析

## 技术栈
- 微信小程序原生开发框架
- 微信云开发（数据库、云函数、云存储）
- 可视化图表
- 人工智能API集成
